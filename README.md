# Chess — Next-generation Chess Platform (Demo)

This is a single-page demo of a modern chess platform built with HTML5, CSS3, and Vanilla JavaScript.

Features included in this demo:
- Playable chessboard with drag-and-drop and click moves
- Legal move validation, check/checkmate/stalemate detection
- Undo / Restart / Flip board
- Simple AI opponent (negamax)
- FEN import/export support in engine
- Responsive layout, glassmorphism UI, animations

To run: open `index.html` in your browser.

Notes: This is a frontend-only demo. Many advanced features (PGN export, timers, full analysis UI, puzzles, tournaments, accessibility polishing) are scaffolded and can be extended.
